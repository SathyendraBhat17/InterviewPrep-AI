# InterviewPrep AI

InterviewPrep AI is an AI-powered interview preparation platform that helps students practice technical interviews through role-specific questions and personalized feedback.

## Problem

Students often struggle to prepare for technical interviews because they lack structured practice, personalized feedback, and role-specific interview questions.

## Solution

InterviewPrep AI uses Google's Gemini API to generate interview questions based on the selected role and difficulty level. It evaluates user answers and provides scores, strengths, weaknesses, and improvement suggestions.

## Features

* AI-generated interview questions
* Role-based interview preparation
* Difficulty level selection
* AI-powered answer evaluation
* Personalized feedback and scoring
* Responsive and professional user interface

## Tech Stack

* HTML
* CSS
* JavaScript
* Gemini API

## Status

Focused on helping students prepare for technical interviews more effectively through AI-powered practice and feedback.
